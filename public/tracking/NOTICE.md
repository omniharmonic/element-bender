# Tracking assets

The JavaScript and WebAssembly runtime in `wasm/` is copied unmodified from `@mediapipe/tasks-vision` version 0.10.21, as pinned by the project lockfile. Preserve the copyright and license notices embedded in those files.

The model files are downloaded unmodified from Google's official model hosting:

- `https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task`
- `https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task`

See the MediaPipe project and model documentation for their terms and model cards:

- https://github.com/google-ai-edge/mediapipe
- https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker
- https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker
